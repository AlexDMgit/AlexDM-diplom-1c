# Инструкция по начальной настройке.

## При первом запуске необходимо произвести первоначальную настройку функционала.

### Все настройки осуществляются в режиме 1С предприятия:

1. Создать пользователя Администратор с профилем прав доступа Администратор.
2. Создать пользователей: Бухгалтер, Кадровик-расчетчик, Специалист, Менеджер по обслуживанию, выбрав соответствующие профили прав доступа с префиксом ВКМ.

### Подсистема Обслуживание клиентов.
1. Под учетной записью администратора настроить [телеграм-бот](https://github.com/netology-code/fonecmid-diplom/blob/onec-mid-31/tasks/telegram.md)
2. Заполнить Константы "Токен управления ТБотом" и "Идентификатор группы оповещения" (где взять значения для констант, написано по ссылке в п.1).
3. Настроить регламентное задание по отправке сообщений телеграм-боту.
4. Создать или выбрать существующую номенклатуру с видом номенклатуры Услуги, которая будет отображаться в актах об оказании услуг клиенту (Рекомендуемые названия для номенклатуры: Абонентская плата и Работы специалиста).
5. Заполнить созданными (выбранными) наименованиями соответствующие константы: "Номенклатура/Абонентская плата" и "Номенклатура/Работы специалиста".

### Перед первым использованием подсистемы "Обслуживание клиентов" Кадровику-расчетчику необходимо сделать следующие настройки: 
1. Подсистема "Обслуживание клиентов" использует справочник "Сотрудники". Первоначально справочник не содержит данных.
2. Кадровик-расчетчик обязательно должен заполнить справочник "Сотрудники" фамилиями сотрудников, и заполнить в регистре сведений "Условия оплаты сотрудников" поле "Процент от работ". Поля регистра "График работ" и "Оклад" можно заполнить позже.

### Перед первым использованием подсистемы "Расчет зарплаты":
1. Заполнить справочник "Графики работ" (например "Пятидневная рабочая неделя"). Для графика "отпуск" имеется предопределенная запись "Отпуск календарные дни". 
2. С помощью обработки "Заполнение графиков работ" нужно заполнить соответствующий график, указав выходные дни. Для графика "Отпуск календарные дни" должны учитываться все дни.
3. Кадровик-расчетчик обязательно должен заполнить в регистре сведений "Условия оплаты сотрудников" поля по графику работы сотрудников и их окладу. Период указывает, с какого числа действуют указанные условия.
4. Кадровик-расчетчик должен  в разделе сервис назначить график отпуска ("Отпуск календарные дни").


## Тестирование

### Сценарии
- Создание заявок на обслуживание с указанием специалистов (МенеджерПО)
- Закрытие заявок на обслуживание с указанием выполненныъ работ (Специалист)
- Массовое создание актов (Бухгалтер)
- Формирование отчета "Анализ выставленных актов" (Бухгалтер)

Автотесты реализованы с помощью Vanessa Automation.

### Настройки и условия для успешного прохождения тестов.

1. Все автотесты запускаются на базе данных AlexDM-diplom.dt
2. Перед первым запуском тестов нужно распаковать файл Тесты.zip в папку
   на жестком диске, и в Менеджере тестирования Vanessa на закладке
   "Сервис-Основные" в строке "Каталог проекта" указать путь к папке,
   в которую распаковали файлы тестов.
3. Перед запуском автотеста клиент-тест должен быть закрыт. Vanessa автоматически
   загрузит клиент-тест и залогинится в нужную учетную запись.
4. Первый запуск тестов нужно производить в определенном порядке,
   так как тесты опираются на данные, созданными предыдущими тестами.
      - "1. Обслуживания клиента (Создание).feature"
      - "2. Обслуживание клекнта (Закрытие).feature"
      - "3. Обработка Массовое создание актов.feature"
      - "4. Отчет Анализ выставленных актов.feature" (+ Эталон.mxl)
5. После первого запуска всех тестов, когда все данные в базе уже будут созданы,
   можно повторно запускать тесты в произвольном порядке.
